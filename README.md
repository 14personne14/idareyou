# IDU (I Dare You)

Multiplayer game for parties with friends or family

## Team

`@personne14` : Do nothing

`@BernardoJBueno` : Do all

## 🚀 Installation

```bash
git clone https://github.com/14personne14/idareyou
cd idareyou
cp .env.example .env
docker compose up --build
```

You should change the .env file

## 🛠️ Technologies

- **Frontend**: React, Vite
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **Containerization**: Docker
